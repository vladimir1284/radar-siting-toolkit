about=Radar Siting Toolkit answers one operational question: given a territory, a set of constraints, and a definition of what area matters, where should one or more weather radars be sited, and what will each configuration see? It computes terrain-horizon blockage and Bech partial-beam-blockage geometry from a DEM, in three modes: Evaluate (score candidate sites), Discover (merit raster over an eligible-terrain mask), and Network (joint coverage, redundancy, and residual gaps across multiple radars). It is not a rain-attenuation, propagation-anomaly, clutter, or cost model — see the README for explicit scope limits.
